OAuth Authorization Server

v08: OpenID Provider — OAuth + OIDC; RS256 id_token; discovery + GET /jwks.

  • GET /authorize — called by the client with client_id, redirect_uri, scope, and nonce
  • POST /token — exchange authorization code or refresh token; returns id_token when openid is in scope
  • GET /.well-known/openid-configuration — OIDC discovery document
  • GET /jwks — JWK Set for RS256 verification
  • GET /userinfo — scoped identity claims (Bearer access token)
  • POST /introspect — RFC 7662; resource server authenticates via service_clients
  • /login
  • /debug/state — shows clients and service_clients separately
