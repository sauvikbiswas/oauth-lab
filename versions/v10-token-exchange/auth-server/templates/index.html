OAuth Authorization Server

v10: v09 resource indicators + RFC 8693 token exchange on POST /token.

  • GET /authorize — client sends resource URI alongside PKCE, scope, and nonce
  • POST /token — authorization code, refresh token, or token exchange
  • GET /.well-known/openid-configuration — OIDC discovery; includes protected_resources (RFC 9728)
  • GET /jwks — JWK Set for RS256 verification
  • GET /userinfo — scoped identity claims (Bearer access token)
  • POST /introspect — RFC 7662; resource server authenticates via service_clients
  • /login
  • /debug/state — shows clients, service_clients, and agent_clients
